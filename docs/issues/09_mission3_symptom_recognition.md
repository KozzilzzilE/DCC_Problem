# [Issue / Mission 3] 환자 증상 9종 인식 (텍스트 기반) 개발 착수

## 1. 배경 및 목표
- 목표: 119 신고 통화 전사 텍스트(JSON)를 기반으로 환자의 증상 9종 중 해당하는 것을 추출 (Multi-label Classification)
- 대상 증상: 고열, 구토, 두통, 복통, 어지러움, 열상, 오심, 전신쇠약, 호흡곤란
- 특징: 음성 오디오를 사용하지 않고 텍스트만을 입력으로 받으므로, 로컬 환경(CPU/MPS)에서도 빠르고 가볍게 개발 가능.

## 2. 세부 태스크
- [ ] JSON 데이터 파싱 및 전처리 로직 구현 (전사 텍스트 + 라벨 매핑)
- [ ] 텍스트 전처리(토큰화) 및 베이스라인 모델(KoBERT, KoELECTRA 등) 선정
- [ ] 모델 학습 및 하이퍼파라미터(Threshold) 튜닝
- [ ] 검증 데이터 대상 성능 측정 (Macro F1-score 타겟)
- [ ] `inference.py`의 `mission3_inference()`에 결과 연동
