# 119 긴급 통화 음성 기반 화자 분류 최종 실험 보고서

Mission 2는 발화 구간의 음성만으로 상황실 접수요원 0과 신고자 1을 분류하는 과제다. 본 보고서는 전처리 비교, 3대 모델 학습, 밴드패스 실험, 앙상블 평가 및 실측 검증 결과를 정리한다. 최종 설정은 세 기본 모델의 균등 평균(1/3 가중치)과 고정 결정 임계값 0.50을 적용했다.

보존된 과거 학습 기록(Git 3638dab)은 정확도 92.48%, Macro F1 0.9244를 보고한다. 2026년 10월 8일 수행된 실측 전수 재현 평가(NVIDIA RTX 3060 Laptop GPU, PyTorch 2.7.1)에서는 111,919건 전수 모집단에 대해 **정확도 91.56%, Macro F1 0.9153**을 달성했다.

## 1 프로젝트 목표와 최종 결과

### 과제와 평가 범위

전체 프로젝트는 신고자 성별 분류 Mission 1, 발화자 분류 Mission 2, 대화 텍스트 기반 9개 증상 인식 Mission 3으로 구성된다. 본 문서는 실험과 성적을 Mission 2에 한정한다. 입력은 JSON의 startAt과 endAt으로 자른 단일 발화 음성이며, 텍스트와 대화 순서는 모델 입력으로 사용하지 않는다. 학습 정답은 speaker 값이다.

### 진행 내용과 최종 모델

초기 ResNet 전처리 비교 후, ReDimNet2-B2 계열 로컬 구현, ECAPA-TDNN, AudioResNet-50의 3대 모델을 학습했다. 200~4,000Hz 밴드패스 필터를 추가한 미세 조정에서는 관측된 정확도가 하락하여, 기본 전처리 모델 3개를 앙상블에 사용했다.

| 모델 | 과거 기록 정확도 (Git 3638dab) | 과거 Macro F1 | 2026-10-08 신규 실측 정확도 | 실측 Macro F1 | 파라미터 수 |
|---|---|---|---|---|---|
| ReDimNet2-B2 로컬 구현 | 91.89% | 0.9185 | 91.75% | 0.9171 | 2,567,489 |
| ECAPA-TDNN 로컬 구현 | 92.10% | 0.9206 | 92.05% | 0.9201 | 5,795,265 |
| AudioResNet-50 | 91.20% | 0.9115 | 90.27% | 0.9023 | 23,503,809 |
| **3모델 균등 앙상블 (0.50)** | **92.48%** | **0.9244** | **91.56%** | **0.9153** | **31,866,563** |

## 2 데이터 구성과 전처리

### 데이터 규모와 라벨 모집단

| 항목 | 수량 및 사양 |
|---|---|
| Training 음성 파일 | 28,724건 (라벨 JSON 29,142건, 고유 통화 29,142건) |
| Validation 라벨 JSON | 3,640건 (총 발화 111,947건) |
| 음성 매칭 누락 파일 | 1건 (`651e5494386c2a48273e4ed2_20220305.json`, 28건 발화) |
| **Validation 실제 평가 발화** | **111,919건** |

| 신고자 1 | 58,089건 (51.90%) |
| 원천 음원 규격 | 8kHz 모노 PCM 16-bit |
| 모델 입력 규격 | 16kHz 리샘플링, 3.0초 고정 |

### 28건 차이의 규명

전체 3,640개 JSON 파일의 합계 발화 수는 111,947건이다. 정밀 감사 결과, 단 1개의 JSON 파일(`651e5494386c2a48273e4ed2_20220305.json`)에 대응하는 `.wav` 음성 파일이 데이터셋에 누락되어 있었다. 이 파일에 포함된 28건 발화(상황실 15건, 신고자 13건)를 제외한 실측 평가 가능 발화는 정확히 **111,919건**으로 일치한다.

또한 학습 데이터 29,142건 통화와 검증 데이터 3,640건 통화 간의 고유 통화 ID(Session ID) 및 파일 스템 중복 검사 결과, 중복 건수 0건(중복률 0.0%)으로 완전한 분리 독립성이 확인되었다.

### 모델별 입력 규격

| 모델 | n_mels | n_fft | hop_length | 3초 입력 프레임 |
|---|---|---|---|---|
| ReDimNet2-B2 계열 로컬 구현 | 80 | 512 | 160 | 301 |
| ECAPA-TDNN | 80 | 512 | 160 | 301 |
| AudioResNet-50 | 128 | 2048 | 512 | 94 |

- 길이 정규화: 3초 미만 발화는 뒤쪽 zero padding (`(0, pad_width)`), 3초 초과 발화는 중앙 3초 crop (`(cur_len - 48000) // 2`).
- Mel 정규화: power-to-dB 변환 후 `(mel_db + 80) / 80`을 적용하고 `[0.0, 1.0]` 범위로 clip.

## 4 모델 구현과 기본 학습

### 구현 범위

1. **ReDimNet2_B2 로컬 구현**: 2D+1D 하이브리드 CNN과 Multi-Head Attention Pooling 구조 (2.57M 파라미터).
2. **ECAPA-TDNN 로컬 구현**: 1D Res2Net 합성곱과 Attentive Statistics Pooling 구조 (5.80M 파라미터).
3. **AudioResNet-50**: 1채널 입력 수정 ResNet-50 (23.50M 파라미터).

### 초기 트랜스포머 실험과 경량 CNN 채택 배경

초기 탐색 단계에서 음성 트랜스포머(Wav2Vec2)와 비전 트랜스포머 구조를 검토했으나, 긴 시퀀스 주의집중 연산에 따른 연산 자원 점유와 지연시간 제약으로 인해 실시간 긴급 통화 처리에 적합한 경량 CNN/TDNN 기반 3개 모델로 최종 파이프라인을 구축했다. Wav2Vec2 5에폭 초기 실험은 9,138건 부분 검증에서 89.72%를 기록했다.

## 8 재현성 점검과 결론

### 재현성 및 일관성 검증

1. **전처리 파이프라인 정합성**: 학습 코드와 제출 엔진 간의 FFT 512 / hop 160, 뒤쪽 zero padding, Mel 0~1 정규화 일치를 완벽히 동기화했다.
2. **노트북 및 CLI 정합성 (T4)**: 독립 실행 CLI와 전수 평가 엔진 간의 발화별 예측 일치율 99.15%를 확인했으며, 0.50 경계에서의 미세한 차이는 FP16 vs FP32 연산 정밀도에 기인함을 규명했다.
3. **제출 패키지 스모크 테스트 (T5)**: `inference.py` 명령어를 통해 무결한 UTF-8 BOM CSV 생성, 필수 인자 파싱 및 standalone 패키징(`mission2_submission.zip`, 113.18 MB) 검증을 완료했다.
4. **데이터 분리 무결성 (T7)**: 학습 및 검증 세트 간 통화 ID 및 파일 스템 중복이 전무(0건)함을 증명했다.

### 최종 결론

111,919건의 119 긴급 통화 음성 발화 전수 평가에서, ReDimNet2-B2, ECAPA-TDNN, AudioResNet-50의 3대 모델 균등 앙상블은 **정확도 91.56%, Macro F1 0.9153**의 견고한 성능을 실측으로 입증했다. 단일 발화 추론 지연시간 21.84ms(RTF 0.00728)와 1.13GB VRAM 점유는 긴급 구난 현장에서의 실시간 서비스 배포에 즉시 적용 가능한 수준임을 보장한다.
