## 1. 전처리 파라미터 최적화 실험 (Ablation Study)

주최 측 멘토 피드백(*"관행적인 기본값 대신 119 통화 데이터에 가장 적합한 전처리 파라미터 조합을 과학적으로 입증할 것"*)을 반영하여, 동일한 ResNet-50 백본 위에서 4가지 전처리 프로토콜을 비교 실험함.

### 📊 전처리 실험 결과표 (동일 3 에포크 기준)

| 실험 ID | 윈도우 길이 | 패딩 방식 | n_fft | n_mels | Val Accuracy (%) | Macro F1 | 비고 및 분석 인사이트 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **Pre-1** | 1.5초 | zero | 2048 | 128 | 84.92% | 0.8480 | 짧은 단답형에 유리하나 긴 호흡/문맥 정보 손실 |
| **Pre-2** | 3.0초 | repeat | 2048 | 128 | 85.14% | 0.8503 | 소리 반복으로 인해 화자의 억양 및 긴장도 왜곡 발생 |
| **Pre-3** | **3.0초** | **zero** | **2048** | **128** | **85.93%** | **0.8584** | 🥇 **최고 성능. 충분한 문맥(3s)과 무음 패딩의 조화** |
| **Pre-4** | 3.0초 | zero | 1024 | 128 | 85.48% | 0.8545 | 짧은 발화 경고는 해소되나 주파수 분별력 다소 저하 |

* **결론 및 채택**: 119 긴급 통화의 화자 판별에는 **3.0초 윈도우 + Zero 패딩 + n_fft 2048 + n_mels 128 (Pre-3)** 조합이 가장 높은 식별력을 보임.

## 2. 베이스라인 모델(AudioResNet-50) 정식 검증 결과

* **모델 아키텍처**: AudioResNet-50 (ImageNet 사전학습 가중치 1채널 평균 블렌딩 + Dropout 0.3 + Linear)
* **검증 데이터 규모**: AI-Hub 서울 소방 데이터셋 Validation 전체 3,640개 파일 중 대표 10,004개 발화 구간
* **전처리 정규화**: Mel-Spectrogram (dB scale) -> `np.clip((mel_db + 80.0) / 80.0, 0.0, 1.0)`

### 🎯 최종 검증 성적

| 평가 지표 | 수치 | 비고 |
| :--- | :---: | :--- |
| **Validation Accuracy** | **90.20%** | 공식 대회 평가 기준 |
| **Macro F1-Score** | **0.9018** | 클래스 간 균형 평가 |
| **119 대원(0) 정답률** | **88.6%** | 4,831개 중 4,282개 정답 (오답 549개) |

## 3. 한계점 분석 및 고득점(93%+) 돌파 전략

### ⚠️ 현재 ResNet-50 베이스라인의 한계
1. **정확도 정체 (약 90.2%)**: 2D 이미지 기반 CNN 특성상, 주파수 대역의 정적 패턴은 잘 읽으나 발화의 시계열적 억양/호흡 변화를 전역적으로 파악하지 못해 90% 초반에서 수렴 한계에 봉착함.
2. **모델 크기 대비 효율성**: 2,350만 개(23.5M) 파라미터로 모바일이나 임베디드 관제 시스템 배포 시 다소 무거움.

### 🚀 향후 추진 전략 (Phase 2: 다중 모델 벤치마크)
1. **ReDimNet2-B2 (3.6M)**: 2D Conv(국소 성도 특징) + 1D Conv(시간 시퀀스) + Multi-Head Attention 결합 구조로 1/6 크기 경량화 및 정확도 향상 검증.
2. **ECAPA-TDNN (6.1M)**: 화자 인식 표준 모델인 통계적 어텐션 풀링을 적용하여 통화 음질 편차 극복.
3. **HuBERT-Base (95M)**: 음향 트랜스포머를 통해 음성 표현력 극대화 및 최고 정확도 상한선 탐색.
4. **Soft Voting 앙상블**: CNN(ResNet) + 화자 특화 모델(ReDimNet) + 트랜스포머(HuBERT) 예측 확률 결합으로 93%+ 달성.
