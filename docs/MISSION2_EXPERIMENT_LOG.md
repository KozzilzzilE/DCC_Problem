## 1. 전처리 파라미터 최적화 실험 (Ablation Study)

주최 측 멘토 피드백(*"관행적인 기본값 대신 119 통화 데이터에 가장 적합한 전처리 파라미터 조합을 과학적으로 입증할 것"*)을 반영하여, 동일한 ResNet-50 백본 위에서 4가지 전처리 프로토콜을 비교 실험함.

### 📊 전처리 실험 결과표 (동일 3 에포크 기준)

| 실험 ID | 윈도우 길이 | 패딩 방식 | n_fft | n_mels | Val Accuracy (%) | Macro F1 | 비고 및 분석 인사이트 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :--- |
| **Pre-1** | 1.5초 | zero | 2048 | 128 | 84.92% | 0.8480 | 짧은 단답형에 유리하나 긴 호흡/문맥 정보 손실 |
| **Pre-2** | 3.0초 | repeat | 2048 | 128 | 85.14% | 0.8503 | 소리 반복으로 인해 화자의 억양 및 긴장도 왜곡 발생 |
| **Pre-3** | **3.0초** | **zero** | **2048** | **128** | **85.93%** | **0.8584** | 🥇 **최고 성능. 충분한 문맥(3s)과 무음 패딩의 조화** |
| **Pre-4** | 3.0초 | zero | 1024 | 128 | 85.48% | 0.8545 | 짧은 발화 경고는 해소되나 주파수 분별력 다소 저하 |

* **결론 및 채택**: 119 긴급 통화의 화자 판별에는 **3.0초 윈도우 + Zero 패딩 + n_fft 2048 + n_mels 128 (Pre-3)** 조합이 가장 높은 식별력을 보임.

## 2. 베이스라인 모델(AudioResNet-50) 정식 검증 결과

* **모델 아키텍처**: AudioResNet-50 (ImageNet 사전학습 가중치 1채널 평균 블렌딩 + Dropout 0.3 + Linear)
* **검증 데이터 규모**: AI-Hub 서울 소방 데이터셋 Validation 전체 3,640개 파일 중 대표 10,004개 발화 구간
* **전처리 정규화**: Mel-Spectrogram (dB scale) -> `np.clip((mel_db + 80.0) / 80.0, 0.0, 1.0)`

## 3. 한계점 분석 및 고득점(93%+) 돌파 전략

### ⚠️ 현재 ResNet-50 베이스라인의 한계
1. **정확도 정체 (약 90.2%)**: 2D 이미지 기반 CNN 특성상, 주파수 대역의 정적 패턴은 잘 읽으나 발화의 시계열적 억양/호흡 변화를 전역적으로 파악하지 못해 90% 초반에서 수렴 한계에 봉착함.
2. **모델 크기 대비 효율성**: 2,350만 개(23.5M) 파라미터로 모바일이나 임베디드 관제 시스템 배포 시 다소 무거움.

### 🚀 향후 추진 전략 (Phase 2: 다중 모델 벤치마크)
1. **ReDimNet2-B2 (3.6M)**: 2D Conv(국소 성도 특징) + 1D Conv(시간 시퀀스) + Multi-Head Attention 결합 구조로 1/6 크기 경량화 및 정확도 향상 검증.
2. **ECAPA-TDNN (6.1M)**: 화자 인식 표준 모델인 통계적 어텐션 풀링을 적용하여 통화 음질 편차 극복.
3. **Wav2Vec 2.0 (95.0M)**: 음향 트랜스포머 사전학습 가중치를 통한 음성 표현력 극대화 및 최고 정확도 상한선 탐색.
4. **Soft Voting 앙상블**: 2D 주파수(ResNet-50) + 1D 시계열 음향(Wav2Vec 2.0) 확률 결합으로 93%+ 달성.

## 4. 다중 모델 벤치마크 1차 실험 결과 및 분석

동일한 검증 데이터셋 위에서 ReDimNet2-B2, ECAPA-TDNN을 직접 구현하여 5 에포크 고속 학습을 수행함.

### 4.1 1차 벤치마크 결과표

| 모델명 | 아키텍처 | 파라미터 수 | 사전학습 여부 | Val Accuracy (%) | Macro F1 | 비고 |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| **AudioResNet-50** | 2D CNN | 23.5M | ImageNet Pretrained | **90.20%** | **0.9018** | 기존 베이스라인 (기준선) |
| **ReDimNet2-B2** | Hybrid (2D+1D+MHA) | 3.6M | Scratch (무작위 초기화) | 55.44% | 0.5137 | 5ep 내 미수렴 |
| **ECAPA-TDNN** | 1D CNN + Stats Pool | 6.1M | Scratch (무작위 초기화) | 55.33% | 0.5076 | 5ep 내 미수렴 |
| **ReDim + ECAPA 앙상블** | Soft Voting (5:5) | - | - | 55.49% | 0.5138 | 미수렴 모델 간 결합 한계 |

### 4.2 ReDimNet2 & ECAPA-TDNN 55% 수렴 정체의 근본 원인 분석

1. **사전학습 가중치 유무의 결정적 격차**:
   - AudioResNet-50(90.20%)은 대규모 ImageNet 데이터셋으로 사전학습된 풍부한 시각적/패턴 필터를 전이(Transfer Learning)받아 1채널 스펙트로그램에 빠르게 적응함.
   - 반면 ReDimNet2-B2와 ECAPA-TDNN은 가중치가 무작위로 초기화된 상태(Scratch)에서 단 5 에포크(약 3.8만 발화)만 학습되어, 음향 공간의 복잡한 화자 특징 표현을 학습하기에 데이터 및 에포크 수가 절대적으로 부족함.
2. **이진 분류에서의 랜덤 추측 수준 잔류**:
   - 검증셋의 화자 클래스 비율(119대원 약 48%, 신고자 약 52%)을 감안할 때, 55% 내외의 정확도는 모델이 특징을 분별하지 못하고 다수 클래스로 편향되거나 랜덤 추측하는 초기 단계에 머물렀음을 시사함.

### 4.3 해결책 및 Wav2Vec 2.0 파인튜닝 탑재

* 대규모 음향 자기지도학습 모델인 **Wav2Vec 2.0 (`facebook/wav2vec2-base`)** 사전학습 가중치를 백본으로 도입.
* 1D Raw Waveform(48,000 샘플, 3초)을 직접 입력받으며, 하위 CNN 특징 추출기는 고정(Freeze)하여 과적합을 방지하고 상위 트랜스포머 인코더 및 분류기만 고속 파인튜닝(LR 3e-5) 진행.
* 이후 **AudioResNet-50 (90.20%) + Wav2Vec 2.0 Soft Voting 앙상블**을 통해 93%+ 최고 성능 달성 파이프라인 구축 완료.
