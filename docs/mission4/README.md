# Mission 4 실험 기록

통화가 진행되는 동안 증상 목록을 갱신하고 판단을 멈출 시점을 정하기 위한 실험의 공개 요약이다. 실험 결과는 개발에 사용된 내부 자료의 집계이며 공식 Validation 성적이나 최종 제출 성적이 아니다.

## 읽는 순서

1. [실험 흐름](EXPERIMENT_HISTORY.md)에서 문제, 비교, 결과와 후속 질문을 읽는다.
2. [결과 표](RESULTS.csv)에서 실행 ID, 조건, seed, 평가 범위와 수치를 확인한다.
3. [팀원 결과 검토](TEAM_RESULT_REVIEW.md)에서 비교 가능한 결과와 추가 확인할 부분을 읽는다.
4. [다음 비교 계획](NEXT_COMPARISON.md)에서 고정 임계값과 공통 분할을 사용하는 후속 절차를 확인한다.
5. [공개 채점 코드](../../mission4_symptom/score.py)에서 점수 계산을 확인한다.

**Seed**는 학습의 초기화와 무작위 순서를 정하는 숫자다. 서로 다른 seed의 결과를 나란히 보면 해당 실행들 사이의 변동을 볼 수 있지만, 두 seed만으로 모든 학습 변동을 알 수는 없다. `ensemble`은 두 seed 모델의 확률을 평균한 한 결과이며 별도 seed가 아니다.

Mission 4-1 점수는 각 시점의 증상 집합 점수를 통화별로 평균한 후 통화별 평균을 다시 평균한다. Accuracy가 아니다. Mission 4-2는 판단 시점의 성능과 조기성을 함께 반영한다. 서로 다른 데이터, 학습량 또는 평가 조건의 점수를 단순히 빼서 한 변경의 효과로 해석하지 않는다.

반복 사용한 개발셋, 별도 유보셋의 한 차례 확인, 개발셋 내부 fold에서의 정책 평가는 각각 구분한다. 이미 선택에 사용한 자료는 새로운 독립 확인셋이 아니다. 통화 단위 신뢰구간은 새로운 학습 seed의 변동을 보장하지 않는다. 미채택은 해당 실험의 사전 기준에 관한 결정이며 효과가 없다는 증명이 아니다.

22,509통화 추가 학습의 2026-11-14 13:26 KST 관찰 당시 두 seed의 학습은 완료됐고 마지막 예측이 진행 중이었다. 이 패키지에는 최종 비교 성적과 이후 보존 검증 결과를 넣지 않았다. 원본 전사·예측·가중치와 상세 감사 기록은 공개 저장소 밖 비공개 위치에 보관한다.

## 제출 규칙 확인 상태

사용자가 확인한 기본 임계값은 **0.50**이다. 이 임계값에서 빈 목록을 유지하는 기본 출력은 고정 규칙의 참고 결과다. 빈 목록에 Top-1을 강제하는 방식은 허용 여부가 확인되지 않아 개발 결과로만 기록한다. 공통·클래스별 임계값을 조정한 방식은 고정 0.50 제출 후보에서 제외하며 탐색 이력으로 남긴다. 개발 단계의 사전 기준 통과는 제출 방식 채택을 뜻하지 않는다.
