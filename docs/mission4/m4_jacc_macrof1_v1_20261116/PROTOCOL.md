## 1. 왜 하는가

1. `m4_softjaccard_v1_s42` (`BCE + 1.0 * SoftJaccard`)는 **4-1 공식 지표**에서 단일 모델만으로 `+0.02366`(`0.502733 → 0.526393`)의 큰 향상을 달성했고 `ENS3` 교체 시에도 `0.506001 → 0.512504`(`+0.006504`, `p_gt0=1.0`)를 기록했다.
2. 그러나 `SoftJaccard`는 표본 단위 합집합 비율이므로 빈도 높은 증상(`복통`, `어지러움`) 위주로 재현율을 높이고 저빈도·모호 클래스(`오심` 최종 F1 `0.361 → 0.329`, `두통` `0.562 → 0.550`) 재현율을 내려, 클래스 균등 평균인 **4-2 `Macro-F1`** 이 단독 기준 `0.6502 → 0.6471`(고정 10발화 `0.5556 → 0.5464`)로 소폭 하락했다.
3. **가설:** `BCE(pos_weight^0.5)` 위에 **`0.5 * SoftJaccard`와 `0.5 * Batch Smoothed Macro-F1 (MacroDice, smooth=1.0)`를 함께 결합**하면, `4-1` 개선 폭을 상당 부분 유지하면서 저빈도 클래스(`오심`·`두통`·`고열`) `Macro-F1` 손실을 막아 **4-1과 4-2를 동시에 개선**할 수 있다.
