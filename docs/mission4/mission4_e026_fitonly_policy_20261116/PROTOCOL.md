## R0: 기존 E026 재현

- 동일 확률·기존 shift·정책으로 `β=0`과 `β=128`을 재채점한다.
- 기대 Dev 4-2: `0.4989532854214187` 대 `0.5031464178054406`.
- 모든 통화의 중단 시점·9개 증상 출력·정답을 저장한다. 원본 집계와 중단 위치가 일치하지 않으면 새 성능 비교로 넘어가지 않는다.

## C0 대 C128: 하나의 정책 변경 비교

| 조건 | 동일한 fit-only shift에서의 중단 정책 |
|---|---|
| C0 | 회귀항을 쓰지 않는 `β=0` |
| C128 | 같은 shift로 특징·표적을 다시 만들고, E026 설정의 회귀모델을 fit/OOF 자료에서 재학습한 `β=128` |

- 분류기 원확률, 입력 통화·시점, 9개 라벨 순서, `p>=0.5`, Top-1 없음, 중단 기준 `>=0.5`, 최소 5발화를 고정한다.
- `β=128`은 이번 실험 전에 고정한다. 새 β 탐색, 새 중단 특징, 모델 교체를 섞지 않는다.
- 기존 정책에 새 shift만 대입하는 것은 정식 C128이 아니다. 특징과 표적을 다시 생성하고 정책을 재학습한다.
- fit-only shift의 라벨 통화와 Dev 통화는 교집합 0이어야 한다. OOF fold별 감독학습 제외 통화도 검사한다.
- 중단 입력에는 현재까지 관측한 정보만 넣는다. 총 발화 수·총 통화 시간·미래 텍스트/확률은 추론 특징에 넣지 않는다. 미래를 달리 붙인 동일 prefix에서 현재 결정이 같은지 시험한다.
- 공식 Validation은 이 비교에서 읽거나 선택에 사용하지 않는다.
