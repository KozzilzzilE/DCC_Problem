## 1. 직전 실험(`m4_precue_bce_v1_s42`)에서 배운 원인

1. `precue_bce_s42`는 `pre-cue` FP를 `31,989 → 28,989`(`-3,000`건) 줄이고 단서 등장 시점 확률 도약을 `+0.4187 → +0.4651`로 날카롭게 만들었지만, 전체 양성 손실 질량이 줄면서 모든 구간의 평균 확률이 내려가 빈 예측률이 `15.15% → 17.14%`로 늘고 4-1 점수는 `-0.005604`(`[-0.00889, -0.00237]`) 하락했다.
2. 반대로 `E002` 확률 위에서 `BCE(pos_weight^0.5)`와 `SoftJaccard = 1 - sum(p*y)/sum(p+y-p*y)` 기울기를 분해 측정한 결과:
   - **다른 정답이 없을 때의 초반 탐색 FP (`n=14,629`)** 에서 `SoftJaccard` 패널티는 `BCE`의 `0.06x`(`0.0048` vs `0.0810`)로 작지만,
   - **정답이 이미 켜진 상태에서의 추가 오탐(`n=12,229`)** 억제(`0.37x`: `0.0276` vs `0.0739`)와 **빈 예측 초반 누락(`n=8,972`)** 회복(`0.38x`: `-0.0649` vs `-0.1699`) 및 **다중 증상 누락(`n=37,815`)** 회복(`-0.0460`)은 강하게 작동한다.
3. 즉 `E024`나 `precue_bce`의 전역 확률 상하 이동 상충을 피하면서, **4-1 공식 지표(Jaccard)와 같은 방향으로 확률 균형을 직접 최적화**할 수 있다.
