## 3. 결정 및 후속 연결

- **해석:** `SoftJaccard`는 표본 단위 Jaccard를 직접 최적화해 **단일 모델 4-1(`+0.02366`)** 과 **`ENS3` 교체 4-1(`+0.00650`)** 을 크게 끌어올렸다. 그러나 저빈도 클래스(`오심`, `두통`)의 재현율을 낮춰 클래스 균등 평균인 **4-2 `Macro-F1`을 깎는 절충**이 나타났다.
- **다음 단계:** 곧바로 `seed 43`이나 `OOF`를 돌리기 전에, `0.5·SoftJaccard + 0.5·Batch SmoothMacroF1`을 결합한 `m4_jacc_macrof1_v1_s42`([PROTOCOL](../m4_jacc_macrof1_v1_20261116/PROTOCOL.md))로 `4-1`과 `4-2 Macro-F1`을 동시에 살릴 수 있는지 먼저 검증한다.
