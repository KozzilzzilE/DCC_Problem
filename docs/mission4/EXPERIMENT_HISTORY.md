# Mission 4 실험의 흐름과 현재 상태

2026-11-14 기준 · 공개 집계 요약

Mission 4는 통화가 한 발화씩 들어올 때 지금까지의 대화로 증상 목록을 갱신하고, 4-2에서는 언제 판단을 멈출지도 정하는 과제다. 데이터 검토에서 짧은 답변의 의미가 앞 질문에 의존하거나 여러 증상이 서로 다른 시점에 나타나는 사례를 확인했다. 이런 관찰은 실험할 질문을 만드는 근거이지, 특정 방법이 효과적이라는 증명은 아니다.

아래 4-1 수치는 공개 채점식 점수이며 **Accuracy가 아니다**. 별도 명시가 없으면 Training에서 나눈 내부 Dev 결과이고, 여러 실험에서 같은 Dev를 반복 사용했다. 실험마다 학습 데이터·입력·예산 등이 다르므로 서로 다른 실험의 점수를 일렬로 빼서 한 변경의 효과로 해석할 수 없다. 통화 단위 신뢰구간은 새 학습 seed의 변동을 모두 설명하지 않는다.

## 1. 전체 통화 학습에서 누적 입력 학습으로

실행 ID: `pilot512_e3_B0_seed42` / `pilot512_e3_B1_seed42`

- **문제와 비교:** 실제 과제는 통화 도중 판단한다. 전체 통화만 학습한 B0와, 앞부분부터 현재까지의 누적 입력을 섞은 B1을 비교했다.
- **결과:** 초기 학습 512통화·내부 Dev 512통화, seed 42에서 4-1은 **0.3914 → 0.4240**이었다. 파일 앞쪽의 작은 표본과 단일 seed 결과다.
- **다음 질문:** B1을 후속 기준선 후보로 두고, 질문과 짧은 응답의 관계를 모델에 더 잘 보여주기 위해 발화 경계와 화자 표시를 비교했다.

## 2. 발화 경계와 화자 표시

실행 ID: `context_expanded_v2_20261112`

- **비교:** 공통 원문과 확대 학습 조건에서 B1 공백 연결, C1 발화 경계, C2 경계와 화자 표시를 비교했다. 학습 2,000통화·내부 Dev 512통화, 각 5epoch와 두 seed다.
- **결과:** 평균은 B1 **0.416200**, C1 **0.415644**, C2 **0.417691**. C2−B1은 seed 42에서 **+0.008402**, seed 43에서 **−0.005422**로 방향이 달랐다.
- **판단과 다음 질문:** 표시가 일관되게 낫다는 근거가 부족해 채택을 보류했다. 이후 오류와 학습 시점 분포를 점검했다.

## 3. 학습할 발화 시점의 선택

실행 ID: `sampling_b1_uniform_v2_20261113`

- **문제와 비교:** 기존 학습은 통화당 전체·초기·후기 입력을 쓰는데, 평가에서는 모든 시점을 본다. 이를 바꾸면 나아지는지 기존 방식과 통화 내 시점 균등 추출을 비교했다.
- **결과:** 기존 → 균등 4-1은 seed 42 **0.435203 → 0.421117**, seed 43 **0.418624 → 0.415598**. 네 예측은 내부 Dev 512통화·15,186시점에서 재채점해 기록과 일치했다.
- **판단과 다음 질문:** 이 두 seed와 고정 조건에서 균등 방식은 미채택이다. 모든 시점 선택 방법의 효과가 없다는 뜻은 아니며, 점수 차이의 원인도 확정하지 않았다. 실제 발화 단서를 놓치는지 별도로 살폈다.

## 4. 발화별 AI 정답과 보조 학습

실행 ID: `evidence_aux_v1_20261113 / evidence_aux_followup_v2_20261113`

- **관찰:** 기존 Dev에서 선택한 **16통화·464발화**를 AI가 미래 발화와 공식 라벨을 가린 채 순서대로 주석했다. 직접 표현 누락과 증상 판단이 후속 발화에서 흔들리는 사례가 있었다. 사람 검수는 대기 중이며 대표적 골든셋이 아니다.
- **비교:** 별도의 학습용 **40통화·1,238발화** AI 주석으로 현재까지 확인된 증상 상태를 학습하는 보조 head를 추가했다. 두 seed에서 동일한 추가 학습 대조군과 비교했다.
- **결과:** 기존 Dev의 보조−대조 평균은 **+0.00498691**로 사전 +0.005 기준에 미달했다. 별도 유보 512통화의 한 차례 확인에서는 **+0.00130128**, 95% CI **[−0.002710, +0.005376]**; seed 42는 **+0.005959**, seed 43은 **−0.003356**이었다.
- **판단과 다음 질문:** 현재 보조 방식의 채택과 자동 풀학습은 보류했다. 단일 증상 개선과 다중 증상 악화가 함께 나타나 미확인 상태의 손실 기여를 따로 살폈다.

## 5. 미확인 상태 손실을 없애거나 절반으로 줄이기

실행 ID: `unknown_component_off_v1_20261113 / unknown_component_half_v1_20261114`

- **문제와 비교:** 보조 주석에는 아직 확인되지 않은 상태가 많다. 이것이 예측을 보수적으로 만드는 데 기여하는지 미확인 성분만 제거하고, 이어서 절반 강도도 비교했다. 미확인은 증상이 없다는 뜻이 아니다.
- **결과:** 완전 제거는 기존 보조 대비 두 seed의 다중 증상 누락을 줄였지만 전체 채택 기준은 미달했다. 절반 강도는 보조 없는 대조군 대비 평균 **+0.005476**이었으나, 기존 보조 대비 평균 다중 점수와 원문 근거 recall이 낮았다.
- **판단과 다음 질문:** 제한된 구성에서 일부 작용을 보여줄 뿐 전체 성능 변화의 단독 원인을 증명하지 않는다. 두 변경 모두 사전 기준에 따라 미채택하고 이 강도 축의 추가 탐색을 종료했다. 다음에는 기본 모델의 데이터 규모를 비교했다.

## 6. 같은 입력 수로 더 다양한 통화 학습

실행 ID: `b1_data_scale_10k_v1_20261114`

- **비교:** 2,000통화 × 5epoch와 10,000통화 × 1epoch를 각각 30,000입력으로 맞췄다. 통화 반복과 학습 순서가 달라지므로 연산량 전체가 완전히 같다는 뜻은 아니다.
- **결과:** 두 seed 평균 **0.426913 → 0.442019**, 차이 **+0.015106**, 95% CI **[−0.001144, +0.030594]**. seed 42는 **0.435203 → 0.448393**, seed 43은 **0.418624 → 0.435645**였다.
- **판단과 다음 질문:** 전체 점수는 두 seed에서 올랐지만 CI가 0을 포함했고 seed 42의 다중 증상 점수는 **0.365112 → 0.351288**로 악화해 사전 독립 확인 기준을 통과하지 못했다. 확대된 데이터를 한 번만 학습한 점을 살펴보고자 같은 10,000통화에 한 epoch를 추가했다.

## 7. 같은 10,000통화에서 한 epoch 추가

실행 ID: `b1_10k_epoch2_v1_20261114`

- **비교:** 기존 학습 상태에서 같은 데이터로 epoch 1 → 2를 진행했다. 추가 최적화와 새로운 시점 추출이 함께 포함된다.
- **결과:** 평균 **0.442019 → 0.446236**, 차이 **+0.004217**, 95% CI **[−0.006264, +0.014858]**. seed 42는 **0.448393 → 0.451499**, seed 43은 **0.435645 → 0.440973**이었다.
- **드러난 점:** 다중 증상 누락은 줄었지만 오탐도 늘었다. 전체 점수 증분은 사전 +0.005 기준에 미달했고 CI도 0을 포함했다. 사후 오류 분해에서는 누락 회복의 이득이 새 오탐 등으로 상당 부분 상쇄됐다. 이는 점수의 산술 분해이지 원인 증명은 아니다.
- **다음 질문:** 전체 대화와 관련된 국소 문맥을 함께 쓰면 누락과 오탐의 절충이 개선되는지 비교했다.

## 8. 전체 문맥과 국소 문맥 결합

실행 ID: `local_fusion_v1_20261114`

- **비교:** 같은 인코더를 고정하고 추가 1,000통화로 결합기를 학습했다. 전체 문맥만 쓰는 대조군과 전체·국소 문맥을 함께 쓰는 후보를 비교했다.
- **결과:** 대조군 평균 **0.434036**, 후보 **0.433431**. 후보−대조는 seed 42 **+0.000708**, seed 43 **−0.001918**이었다. 기존 인코더 평균은 **0.446236**이었다. 빈 출력 비율은 기존 **15.48%**에서 결합기 약 **29.5~30.3%**로 늘었다.
- **판단과 다음 질문:** 다중 누락은 일부 줄었으나 전체 사전 기준에 미달해 미채택했다. 후속으로 양성 가중치를 정렬해도 국소 결합의 추가 이득은 일관되지 않았다. 빈 출력을 비롯한 후처리의 영향을 별도로 비교했다.

## 9. 빈 출력 보정과 두 seed 앙상블 — 개발 탐색

실행 ID: `decision_calibration_v1_20261114`

- **비교:** 인코더 학습에 쓰지 않은 Training 1,000통화 `cal1k`를 보정에 쓰고 내부 Dev에서 평가했다. 빈 목록일 때 가장 높은 증상 하나를 넣는 Top-1 규칙, 임계값 조정, 두 seed 확률 평균을 비교했다.
- **결과:** 단일 모델 두 seed 평균 기준 **0.446236 → Top-1 0.474864**; 다중 증상 평균도 **0.381832 → 0.405368**로 올랐고 개발 단계 사전 4기준을 통과했다. 이는 제출 채택이 아니며 Top-1 강제 출력의 허용 여부는 미확인이다. 임계값 조정 단일 모델은 평균 **0.500239**였지만 다중 점수는 **0.363670**으로 하락했다.
- **앙상블:** Top-1은 **0.489892**, 다중 **0.414129**. 탐색 조건 중 클래스별 임계값 앙상블은 **0.508124**였지만 다중은 **0.385556**이었다. 이 수치는 반복 사용한 개발셋 결과이며 최종 독립 확인 성적이 아니다. 사용자가 확인한 기본 임계값은 0.50이므로 공통·클래스별 임계값 조정은 탐색 이력으로 남기고 고정 0.50 제출 후보에서는 제외한다.
- **다음 질문:** 같은 예측으로 언제 통화를 멈출지 4-2 정책을 비교했다.

## 10. 언제 판단을 멈출지: Mission 4-2

실행 ID: `decision_calibration_v1_20261114`

- **비교:** 두 seed 앙상블과 Top-1 규칙에서 끝까지 듣는 정책과, 확신도·목록 안정성에 따른 적응형 중단을 비교했다.
- **결과:** 끝까지 듣기 **0.308797**, 2-fold OOF 적응 중단 **0.459196**, 평균 중단 **10.30발화**였다. 4-2는 증상 성능과 조기 판단을 함께 반영하는 별도 점수다.
- **한계와 다음 단계:** 개발셋 내부 fold를 이용한 비교이며 새로운 독립 확인은 아니다. 여기의 Top-1 강제 출력은 제출 허용 여부를 확인하지 못했다. 정책과 후처리를 고정해 선택에 쓰지 않은 허용 표본에서 확인해야 한다.

## 11. 현재 전체 학습 데이터 확대

실행 ID: `b1_full22k_cosine_v1_20261114`

- **질문:** 남은 학습 통화를 반영해 기존 10,000통화 모델을 더 확장할 수 있는지 확인한다. 해당 실행은 전체 학습 분할 중 **22,509통화 × 1 추가 epoch**, warmup과 cosine 학습률을 사용한다.
- **상태:** 2026-11-14 13:26 KST 확인 시 두 seed의 학습 완료, seed 42 확인 예측 완료, seed 43 최종 예측 진행 상태였다. 이후의 최종 비교 점수와 보존 상태는 이 공개 요약에서 확인하지 않았다.
- **비교 범위:** 보정용1,000통화는 인코더 학습에서 제외하고 새 확인용512통화로 이전 모델과 비교한다. 데이터 확대·추가 학습·학습률 및 스케줄을 함께 바꾼 구성으로, 개선이 나오더라도 데이터 확대만의 효과라고 단정하지 않는다.
- **남은 일:** seed 43 산출물을 회수하고 실물·해시·재채점을 확인한 뒤 사전 기준에 따라 비교한다. 독립 확인과 최종 채택은 별도 단계다.

## 운영 이력과 준비 중인 아이디어

- **샘플링 v1:** 실제 256배치 저장 후 재개할 때 중단 플래그 제거가 실행 인자 동결 검사에 걸려 종료됐다. 성능 실패가 아니며, v2를 새 실행으로 시작해 실제 재개와 최종 예측을 확인했다.
- **국소 결합:** 마지막 비교 단계에서 JSON 직렬화 오류가 발생했다. 동결 실행 코드를 바꾸지 않고 별도 감사로 같은 비교와 재채점을 복구했다.
- **10k epoch 2 seed 43:** 최종 모델은 확인했지만 마지막 optimizer 상태는 회수하지 못했고, 실제 회수한 전체 재개 상태는 **batch 3,328**까지다. 최종 모델과 중간 optimizer를 정상적인 최종 재개 상태로 묶을 수 없다.
- **준비만 한 후보:** 양성 손실 배수 2, NLI, SBERT 및 MIL은 이 흐름에서 완료된 성능 비교로 취급하지 않는다. 별도 질문·기준·실행과 검증이 필요하다.

미채택은 해당 조건과 사전 기준에서의 판단이다. 효과가 전혀 없다는 증명이나 모든 데이터에 대한 결론으로 확대하지 않는다. 원인 가설과 실제로 관찰된 차이를 구분하고, 사용한 Dev와 유보셋을 이후 새 독립 확인셋으로 다시 부르지 않는다.

원본 전사, 예측, 가중치와 상세 감사 기록은 공개 저장소 밖의 비공개 위치에 보관한다. 이 문서의 집계와 검증 범위는 당시 실험 기록의 요약이다. [숫자별 결과](RESULTS.csv) · [읽는 방법](README.md)
