## 1. 초기 355건 표본 정량 음향 통계 (탐색 가설)

초기 학습 데이터 내 355개 발화 세그먼트(16kHz 기준)를 대상으로 신호 처리를 수행했던 과거 통계치입니다.

| 분석 지표 | 구급대원 / 상황실 (Label 0) | 신고자 (Label 1) | 음향학적 해석 및 초기 가설 |
| :--- | :---: | :---: | :--- |
| **평균 발화 길이** | **2.11초** | **2.38초** | 짧은 대화 구조. 신고자가 상황 설명으로 다소 길게 발화 |
| **음량 요동 편차 (RMS Std)** | **0.0376** | **0.0488** | 신고자의 볼륨 기복이 큼. 당황/호흡 불안정에 의한 진폭 요동 가설 |
| **주파수 에너지 중심 (Centroid)** | **1,070.9 Hz** | **891.8 Hz** | 대원은 고른 포먼트 발성, 신고자는 낮게 웅얼대거나 급격한 고음 혼재 가설 |
| **영교차율 (ZCR)** | **0.1048** | **0.0900** | 대원은 입 앞 고정 마이크로 자음이 캡처되는 특성 가설 |
| **전화 음원 대역** | **300 ~ 3,400 Hz** | **300 ~ 3,400 Hz** | 8kHz PSTN 전화망 통화의 양 클래스 공통 대역폭 특성 |

## 2. 초기 도메인 특성 비교 가설

```mermaid
graph LR
  subgraph 구급대원["구급대원 (Class 0)"]
    A1["감정: 침착, 통제됨"]
    A2["어휘: 표준 프로토콜 질문"]
    A3["음향: 일정한 볼륨 & 마이크"]
  end
  subgraph 신고자["신고자 (Class 1)"]
    B1["감정: 공포, 당황, 고통"]
    B2["어휘: 호소, 말더듬, 개인정보"]
    B3["음향: 극심한 볼륨 기복 & 소음"]
  end
```

### (1) 감정 및 피치(음정, F0) 특성 가설
- **구급대원**: 통제된 감정 상태. 질문과 확인 과정에서 일정한 어조 유지. 피치(F0)의 표준편차가 낮고 억양 곡선이 규칙적임.
- **신고자**: 공포와 패닉 상태. 억양 곡선이 불규칙하며 감정 격앙에 따른 급격한 피치 요동 관찰.

### (2) 스펙트럼 중심 (Spectral Centroid)
- 구급대원의 Centroid(1,070.9Hz)가 신고자(891.8Hz)보다 높게 측정되었으나, 이는 F0(피치)와는 다른 물리량(주파수 가중 평균)임.

### (3) 영교차율 (Zero-Crossing Rate, ZCR)
- 구급대원(0.1048)이 신고자(0.0900)보다 높게 나타남. ZCR은 신호가 0을 통과하는 비율이며 마찰음/파열음 비중 및 고주파 성분과 상관관계를 가짐.
