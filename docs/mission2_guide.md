# 🚨 Mission 2: 신고자 vs 119대원 음성 분류기 (Speaker Classification) 가이드

본 문서는 **데이터+AI 크리에이터 캠프 본선 Mission 2** 해결을 위해 구현된 딥러닝 파이프라인의 핵심 전략과 코드 실행 방법을 안내합니다.

---

## 🧠 1. 모델 구현 및 아키텍처 전략

본 프로젝트는 주최 측의 규칙("텍스트(Annotation) 사용 불가, 오직 오디오만 사용")을 엄격하게 준수하여 **오디오 음향 특징(Acoustic Feature)만으로 화자를 분류하는 모델**을 구축했습니다.

### 1) 오디오의 이미지화 (Mel-Spectrogram)
단순한 1차원 오디오 파형(Waveform) 대신, 주파수 대역별 소리의 크기(dB)를 2차원 이미지로 나타내는 **Mel-Spectrogram** 기법을 사용했습니다. 이를 통해 모델은 배경 소음(사이렌, 길거리 소음)이나 비식별화 처리('삐' 기계음) 같은 시각적 패턴을 효과적으로 학습합니다.

### 2) AudioResNet (1-Channel ResNet50)
이미지 분류에 탁월한 성능을 자랑하는 사전 학습된(Pre-trained) **ResNet50** 모델을 뼈대로 사용합니다.
- 원래 3채널(RGB) 컬러 이미지를 받는 ResNet의 첫 번째 레이어를 수정하여 **1채널(흑백) 스펙트로그램**을 받을 수 있도록 개조(`nn.Conv2d(1, ...)`)했습니다.
- 전이 학습(Transfer Learning)을 통해 빠르게 수렴하고 높은 정확도를 확보합니다.

## 🛠️ 2. 핵심 알고리즘 (훈련 vs 추론)

데이터의 길이가 제각각인 문제를 해결하기 위해 훈련(Train) 단계와 실전 추론(Inference) 단계에서 각기 다른 강력한 전략을 채택했습니다.

### [훈련 단계] Random Crop (데이터 증강 효과)
- 10초짜리 오디오가 들어오면 무조건 앞부분만 자르지 않고, **랜덤한 위치에서 3초를 잘라서(Random Crop)** 모델에 공급합니다.
- 이를 통해 모델은 발화의 도입부, 중간부(삐 소리 등), 후반부의 다양한 특징을 골고루 학습하게 됩니다.

### [추론 단계] 앙상블 기법 (Sliding Window & Soft Voting)
실전 추론(`inference.py`)에서는 버려지는 오디오 정보가 단 1초도 없도록 **슬라이딩 윈도우 및 소프트 보팅** 기법을 적용했습니다.

1. **Sliding Window (겹치게 자르기):** 
   긴 오디오를 한 번만 자르는 것이 아니라, 3초 규격의 돋보기를 절반(1.5초)씩 겹치게 이동하며 **여러 장의 이미지**로 쪼개어 모두 검사합니다.
2. **Soft Voting (확률 다수결 투표):** 
   쪼개진 여러 이미지의 예측값(0 또는 1)을 단순히 세는 것이 아니라, **모델의 확신도(Probability, 0.0~1.0)**를 평균 냅니다. 동률(2:2) 상황에서도 모델이 더 강력하게 확신하는 쪽으로 최종 판정을 내리는 매우 견고한 알고리즘입니다.

## 🚀 3. 코드 실행 가이드 (How to Run)

모든 데이터(data 폴더)가 제자리에 있다면, 다음 두 단계를 거쳐 제출용 CSV 파일을 생성할 수 있습니다.

### Step 1: 모델 훈련시키기 (가중치 생성)
1. VS Code에서 `C:\Users\user\Desktop\DCC\mission2_speaker\model_train.ipynb` 파일을 엽니다.
2. 주피터 노트북의 모든 셀을 맨 위부터 순서대로 실행(`Shift + Enter`)합니다.
3. 중간에 추가된 **[데이터 시각화]** 셀을 통해 스펙트로그램 이미지를 눈으로 확인해 봅니다.
4. 모든 학습(Train Loop)이 끝나면 맨 마지막 셀에서 **최고의 모델 가중치(`best_model.pt`)** 파일이 생성 및 저장됩니다.

### Step 2: 실전 추론 및 CSV 파일 생성
1. VS Code 상단 메뉴에서 `Terminal` -> `New Terminal`을 열어 줍니다.
2. 현재 터미널 경로가 `C:\Users\user\Desktop\DCC` 인지 확인합니다.
3. 아래 명령어를 복사하여 붙여넣고 `Enter`를 칩니다!

```bash
python inference.py --audio_dir data/val/audio --label_dir data/val/label --ckpt_path best_model.pt --output outputs/mission2.csv
```

4. 터미널 창에 추론 진행률(tqdm) 바가 차오르며, 마지막에 **총 정답률(Accuracy)과 함께 결과가 `outputs/mission2.csv`에 성공적으로 저장**되었다는 메시지가 뜨면 모든 미션이 완료된 것입니다!
