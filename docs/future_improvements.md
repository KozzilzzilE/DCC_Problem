# 🚀 모델 성능 개선을 위한 퓨처 워크 (Future Work)

현재 구축된 화자 분류(신고자 vs 119대원) 모델의 성능을 극대화하기 위해 앞으로 팀이 시도해볼 수 있는 4가지 핵심 개선 전략을 정리합니다.

## 1. 🛠️ 치명적 디테일 수정: 빈 공간 패딩(Padding) 값 변경
- **문제점:** 현재 짧은 오디오를 고정 길이(3초)로 맞출 때 패딩 값으로 기본값(0)을 사용하고 있습니다. 딥러닝 주파수 데이터(dB)에서 0은 '가장 시끄러운 굉음'을 의미하므로, AI에게 노이즈로 작용합니다.
- **해결책:** 
p.pad 함수를 사용할 때 constant_values를 완전히 조용한 침묵 상태를 뜻하는 최소값(예: -80dB)으로 설정하도록 코드를 단 한 줄 수정합니다. 가장 적은 노력으로 즉각적인 성능 향상을 기대할 수 있습니다.

## 2. 🎨 특징 결합: 3채널 오디오 퓨전 (RGB 결합 기법)
- **문제점:** 원래 컬러 이미지(Red, Green, Blue)를 처리하기 위해 태어난 강력한 ResNet50 모델을 흑백(1채널)으로만 사용하고 있어 모델의 잠재력을 100% 활용하지 못하고 있습니다.
- **해결책:** 소리를 이미지로 만들 때 3가지 각기 다른 음향 특징을 뽑아내어 3채널 이미지로 합성합니다.
  - **R 채널:** Mel-Spectrogram (전반적인 주파수 에너지)
  - **G 채널:** MFCC (음성 인식 특화 특징, 사람의 발음 톤)
  - **B 채널:** Chroma (음계, 화음 특징)
- AI에게 단일 힌트가 아닌 3배 더 풍부한 힌트를 제공하여 판별력을 폭발적으로 높일 수 있습니다.

## 3. 🎭 데이터 증강: SpecAugment 기법 도입
- **문제점:** 학습 데이터가 한정되어 있어, AI가 특정 정답을 외워버리는 과적합(Overfitting) 문제가 발생할 수 있습니다.
- **해결책:** 음성 AI 업계 표준 데이터 증강 기법인 **SpecAugment**를 적용합니다. 주파수 이미지의 특정 시간대나 특정 주파수 대역을 랜덤으로 까맣게 가려버린 상태로 학습시킵니다. "삐 소리"나 "숨소리" 일부가 가려진 악조건 속에서도 모델이 전체적인 맥락을 파악하도록 가혹하게 훈련시킬 수 있습니다.

## 4. 🤖 최종 무기: 모델 앙상블 (집단 지성 결합)
- **문제점:** 단일 모델(ResNet50)에만 의존할 경우, 모델 구조의 한계로 인해 발생하는 오답을 방어할 수 없습니다.
- **해결책:** ResNet50 외에 내부 구조가 아예 다른 모델(예: EfficientNet)을 하나 더 추가로 훈련시킵니다. 실전 평가(inference.py)를 수행할 때 두 모델이 예측한 확률값을 더하여 평균(Soft Voting)을 냅니다. 하나의 모델이 실수하더라도 다른 모델이 이를 보완해 주어 리더보드 점수 1등을 노리는 데 필수적인 기술입니다.
