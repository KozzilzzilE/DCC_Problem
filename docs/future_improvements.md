# 모델 성능 개선을 위한 퓨처 워크 (Future Work)

> [!NOTE]
> **안내**: 본 문서는 프로젝트 초기에 작성된 추가 연구 아이디어 메모입니다.
> 디지털 오디오 파형의 0 패딩(np.pad constant_values=0.0)은 완전 무음(Zero Amplitude)을 의미하며 정상 동작합니다.

화자 분류 모델의 성능을 추가로 향상시키기 위해 향후 시도해볼 수 있는 개선 전략을 정리합니다.

## 1. 다양한 윈도우 길이 및 적응형 패딩 기법
- 현재 고정 길이 3초 패딩/크롭 방식을 다양한 발화 길이에 맞추어 동적 배치(Dynamic Batching) 또는 적응형 세그먼트 샘플링으로 확장하는 방안.

## 2. 다채널 특징 결합 (Mel + MFCC + Chroma)
- 1채널 멜 스펙트로그램에 MFCC 및 음성 특징을 결합하여 다채널 입력으로 구성하는 방안 (단, 새로운 백본 구조의 초기 학습 필요).

## 3. 데이터 증강 (SpecAugment)
- 멜 스펙트로그램에 시간 마스킹과 주파수 마스킹을 적용하여 모델의 일반화 성능을 높이는 기법.

## 4. 손실 함수 최적화
- 클래스 불균형 및 어려운 샘플에 집중하는 Focal Loss 또는 Cosine Angular Margin 기반 화자 손실 함수 도입.
