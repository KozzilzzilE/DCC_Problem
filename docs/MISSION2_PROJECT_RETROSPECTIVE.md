# 🚒 [Mission 2] 음성 화자 분류 프로젝트 회고 및 개선 방향 (Retrospective & Future Work)

> **작성일자**: 2026-09-19
> **작성목적**: Mission 2 (신고자 vs 119대원 음성 이진 분류) 프로젝트의 전체 진행 흐름 요약과 현재까지의 한계점, 그리고 향후 성능 향상 방안 정리.

---

## 1. 프로젝트 진행 요약 (Progress Summary)

본 프로젝트는 119 긴급 통화 데이터의 특성에 최적화된 모델을 구축하고, 컴퓨팅 자원의 한계를 극복하여 최고의 분류 정확도를 달성하기 위해 3단계로 진행되었습니다.

### ⏱️ Phase 1. 베이스라인 구축 및 전처리 최적화 (Ablation Study)
*   **전처리 실험**: 119 통화 특유의 다양한 길이(단답형~긴 호흡)에 대응하기 위해 윈도우 크기와 패딩 방식을 실험. **3.0초 윈도우 + Zero 패딩**이 억양 왜곡 없이 가장 우수한 성적을 냄을 과학적으로 입증.
*   **베이스라인 모델**: 2D 이미지 분류기인 `AudioResNet-50`에 ImageNet 가중치를 전이 학습시킴.
*   **결과**: 검증 데이터 기준 **90.20%**의 정확도 달성. 2D CNN의 시각적 패턴 인식의 강점과 시계열 문맥 파악의 한계를 동시에 확인.

### ⏱️ Phase 2. 다중 모델 벤치마크 및 파이프라인 안정화
*   **다중 모델 투입**: 1D 시계열 파악과 경량화, 화자 인식 특화 성능을 테스트하기 위해 `ReDimNet2-B2(초경량)`, `ECAPA-TDNN(화자 표준)`, `Wav2Vec 2.0(대형 트랜스포머)`, 그리고 `HuBERT-Base` 투입.
*   **이슈 해결 및 타임아웃**: 초기 55% 정확도 정체(침묵 데이터 반환 버그)를 발견하고, 검증된 `librosa` 파이프라인으로 롤백 및 차등 학습률(Differential LR)을 적용하여 정상 수렴 확인. 단, `HuBERT` 모델은 대용량 가중치 다운로드 직후 **코랩(T4) 세션 만료(Timeout)로 인해 학습을 완료하지 못하고 중단됨.**
*   **결과 (빠른 프로토타이핑 및 벤치마크 성적표)**: 코랩 타임아웃을 피하기 위해 1,500개의 서브셋만 학습시켰음에도 우수한 성능 확보.
    | 순위 | 모델명 | 파라미터 수 | Val Acc (%) | Macro F1 | 비고 |
    | :---: | :--- | :---: | :---: | :---: | :--- |
    | 🥇 | **AudioResNet-50** | 23.5M | **90.20%** | 0.9018 | 기존 단일 1위 (ImageNet 사전학습 전이) |
    | 🥈 | **Wav2Vec 2.0** | 95.0M | **89.72%** | 0.8965 | 1D 모델 1위 (시계열 음향 문맥 포착) |
    | 🥉 | **ReDimNet2-B2** | 3.6M | **88.45%** | 0.8840 | 🌟 초경량 1위 (ResNet 대비 1/6 크기) |
    | 4 | **ECAPA-TDNN** | 6.1M | **86.99%** | 0.8691 | 화자 인식 글로벌 표준 구조 |
    | 🏆 | **최종 앙상블** (ResNet + Wav2Vec) | - | **91.05%** | 0.9101 | **Soft Voting 벤치마크 최고 성능 갱신** |

### ⏱️ Phase 3. 듀얼 트랙(Local-Colab) 병렬화 및 SOTA 모델 도입
*   **전략**: 서브셋이 아닌 100% 전체 데이터를 활용하고, 화자 분류에 특화된 최고 성능 모델을 앙상블하여 93~95%를 돌파하는 전략.
*   **실행**:
    1.  **WavLM-Base+ 도입**: 화자 구별과 노이즈 강건성에 특화된 마이크로소프트의 SOTA 모델 투입.
    2.  **데이터 증강**: SpecAugment(주파수/시간 마스킹), Gaussian Noise 등 노이즈 훈련 기법 코드 작성.
    3.  **환경 분리(Dual-Track)**: VRAM이 넉넉한 Colab(T4)에서는 대형 `WavLM`을, 시간제한이 없는 로컬(RTX 3060)에서는 100% 데이터를 활용한 `ResNet-50` 풀학습을 진행하여 최종 앙상블하도록 설계 완료.

## 2. 현재 방식의 한계점 및 부족한 점 (Limitations)

지금까지 이룬 성과에도 불구하고, 설계 및 환경적 요인으로 인한 명확한 한계점들이 존재합니다.

1.  **코랩(Colab) 환경 종속성에 따른 데이터 병목**
    *   **문제**: 무료/기본 Colab 세션의 시간 및 디스크 I/O 제한으로 인해, 전체 수만 개의 발화 데이터를 한 번에 학습시키지 못하고 서브셋(1,500개)에 의존하여 1차 벤치마크를 진행해야 했습니다.
    *   **결과**: 모델들이 데이터가 가진 전체 분포를 완벽히 학습하지 못해 잠재 성능(Capacity)을 100% 끌어내지 못했습니다.
2.  **노이즈 훈련(Augmentation)의 부재 (Phase 1, 2 기준)**
    *   **문제**: 119 통화는 사이렌, 바람 소리, 울음소리 등 극한의 노이즈가 섞여 있으나, 베이스라인과 1차 벤치마크 모델들은 비교적 깔끔하게 정규화된(Normalized) 스펙트로그램에 의존해 학습했습니다.
    *   **결과**: 깨끗한 음성에서는 강하지만, 극심한 노이즈가 낀 실제 현장 음성에서는 예측 신뢰도(Confidence)가 떨어질 수 있습니다.
3.  **데이터 클래스 불균형(Class Imbalance) 대응 미흡**
    *   **문제**: 신고자(52%)와 119대원(48%)의 비율이 비슷해 보이지만, 발화의 길이와 특성은 완전히 다릅니다. (신고자는 길고 감정적, 대원은 짧고 정형화됨).
    *   **결과**: 단순히 CrossEntropy Loss를 사용함으로써, 맞추기 어려운(Hard Example) 긴박한 통화 내용에 모델이 충분히 집중하지 못하는 현상이 발생할 수 있습니다.
4.  **단순 Soft-Voting 앙상블의 한계**
    *   **문제**: 현재 앙상블 방식은 단순히 모델들의 예측 확률(Logits)을 더해서 평균을 내는 방식입니다.
    *   **결과**: 특정 상황(예: 백색잡음 환경)에서 WavLM이 ResNet보다 훨씬 정확함에도, 두 모델에 동일한 가중치가 부여되어 성능 향상폭이 둔화될 수 있습니다.

## 3. 향후 성능 향상을 위한 전략 (Future Improvements)

위의 한계점들을 극복하고 목표(93% 이상)를 달성하기 위해 적용해야 할 개선 방안입니다.

1.  **전체 데이터 100% 풀학습 실시 (현재 준비 완료)**
    *   **방안**: Phase 3에서 구축한 **'로컬 RTX 3060(ResNet) + Colab(WavLM)' 병렬 학습 시스템**을 가동하여 서브셋이 아닌 전체 데이터를 모델에 쏟아붓습니다. 데이터 크기가 10배 늘어나는 만큼 가장 확실한 정확도 상승(+2~3%p)을 기대할 수 있습니다.
2.  **하드코어 데이터 증강(Hardcore Augmentation) 100% 적용**
    *   **방안**: 모델이 실전 노이즈에 적응하도록, 학습 시 파이프라인에 `SpecAugment` (주파수/시간 축 무작위 삭제), `Gaussian Noise` 추가, `Random 주파수 Gain` (볼륨 조절)을 필수적으로 활성화합니다.
3.  **Focal Loss 및 하드 샘플 마이닝(Hard Sample Mining) 도입**
    *   **방안**: 모델이 이미 잘 맞추는 '네, 119입니다' 같은 쉬운 음성에 대한 학습 비중은 줄이고, 모델이 헷갈려 하는 노이즈 가득한 음성(Hard Example)에 페널티 가중치를 주는 **Focal Loss** 함수로 교체합니다.
4.  **고급 앙상블 (Meta-Classifier / Stacking)**
    *   **방안**: 단순 1:1 평균이 아니라, ResNet과 WavLM의 결과값을 입력으로 받아 최종 판단을 내리는 얕은 머신러닝 모델(예: Logistic Regression, XGBoost)을 하나 더 학습시킵니다. 이를 통해 모델 간의 장단점을 자동으로 파악하여 가중치를 최적화할 수 있습니다.
5.  **화자 임베딩(Speaker Embedding) 기반의 Triplet Loss 적용**
    *   **방안**: 단순히 0(대원)과 1(신고자)을 분류하는 것을 넘어, 같은 119대원의 목소리는 수학적 공간에서 뭉치게 하고, 대원과 신고자의 목소리는 멀어지도록 학습시키는 화자 인식 특화 기법(Triplet Margin Loss)을 추가 적용해 볼 수 있습니다.
