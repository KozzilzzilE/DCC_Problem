# Mission 2 119 긴급 통화 화자 분류

음성 발화 구간으로 상황실 접수요원 0과 신고자 1을 분류한다. 최종 설정은 세 모델 확률의 균등 평균과 고정 임계값 0.50이다.

보존된 학습 노트북 로그는 Validation **111,919건에서 정확도 92.48%, Macro F1 0.9244**를 보고한다. 2026년 10월 8일 수행된 실측 전수 평가(NVIDIA RTX 3060 GPU, PyTorch 2.7.1)에서는 동일한 111,919건 모집단에 대해 **정확도 91.56%, Macro F1 0.9153**을 달성했다.

## 실행

미션 폴더에서 다음 명령을 실행한다.

```bash
pip install -r requirements.txt
python inference.py --audio_dir ../data/val/audio --label_dir ../data/val/label --ckpt_path checkpoints/ --output ../outputs/mission2.csv
```

`--ckpt_path`에 세 가중치가 있는 폴더를 주면 앙상블을, 특정 `.pt` 파일을 주면 그 모델 하나를 사용한다. 세 checkpoint 파일은 `best_redimnet.pt`, `best_ecapa_tdnn.pt`, `best_resnet50.pt`이다. 출력 CSV의 열은 `audio file name`, `startAt`, `endAt`, `speaker`다. `startAt`과 `endAt`은 밀리초이며 화자 판정에 텍스트나 발화 순서를 사용하지 않는다.

## 전처리 규격

입력은 16kHz 모노 3초(48,000 샘플)로 맞춘다.
- 짧은 발화: 뒤쪽 zero padding (`(0, pad_width)`)
- 긴 발화: 중앙 3초 crop (`(cur_len - 48000) // 2`)
- ReDimNet 계열 로컬 구현 및 ECAPA-TDNN: Mel 80 / FFT 512 / hop 160 (301 프레임)
- AudioResNet-50: Mel 128 / FFT 2048 / hop 512 (94 프레임)
- Mel 정규화: 상대 dB를 `(mel_db + 80) / 80`으로 변환 후 `[0.0, 1.0]`으로 clip

## 평가 모집단과 28건 차이 규명

전체 3,640개 JSON 파일의 총 발화 수는 111,947건이다. 이 중 1개 JSON 파일(`651e5494386c2a48273e4ed2_20220305.json`)에 대응하는 WAV 음성 파일이 데이터셋에 존재하지 않는다. 해당 파일의 발화 28건(상황실 15건, 신고자 13건)을 제외하면 음성 데이터가 매칭되는 실제 평가 가능 발화는 정확히 **111,919건**이다.

- 상황실 접수요원 0: 53,830건 (48.10%)
- 신고자 1: 58,089건 (51.90%)
- 총 평가 가능 발화: 111,919건 (100.0%)

또한 29,142건의 학습 통화와 3,640건의 검증 통화는 통화 ID(Session ID)와 파일 스템 수준에서 중복률 0.0%로 완벽히 분리되어 있어 데이터 누수가 없다.
