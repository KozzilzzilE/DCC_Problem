- 1개 통화의 헛짚기를 완벽히 없애도 4-2 는 +0.004~+0.010 인데, 3개 이상 통화를 1위 하나만 내고 포기하면 -0.019 다.

- fit 라벨의 동시 출현은 뚜렷한데(어지러움-오심 J +1.68, 구토-오심 +1.48) 사전으로 온전히 넣으면 4-1 이 -0.005 내려간다. dev 에서 다시 적합한 J 는 +0.49, +0.26 으로 줄어든다. 모델이 이미 확률에 넣어 둔 관계다.
