- 정확성: 사전분포를 fit 26,280통화 라벨로 독립 재계산한 값과 최대 차 2e-23, 기대 점수는 따로 만든 511×511 표와 1e-15 이내. 극단 입력(전부 0, 1e-30, 1, 동률, one-hot, float32/64)에서 빈 예측·NaN·예외 0건.
- 규정: 추론이 쓰는 입력은 전사와 화자뿐이다. 통화 200건을 역순으로 넣거나, 중간에서 자르거나, 다른 통화 뒤에 reset 해서 넣어도 결과가 같았다. 같은 장치에서 반복 실행한 결과도 같다.
- 4-2 불변: 새 번들의 4-2 결과가 이전과 같고, `label_prior` 가 없는 예전 번들도 예전 결과 그대로다.
- 실제 경로와 모의 채점이 6,065개 순간 중 8개에서 다른 이유: 논리 차이가 아니다. 입력 전사는 0건 다르고, 8건 모두 최선 k 와 차선 k 의 기대 점수 차가 3.7e-4 이하이거나 순위가 1e-3 안에서 뒤바뀐 경계 순간이다. 확률의 미세한 차이(중앙 2e-4)는 번들이 가중치를 fp16 으로 저장하는 것과 단건·배치 계산 차이에서 온다.
- **장치에 따라 출력이 조금 다르다**: cuda 와 cpu 의 예측이 6,065개 순간 중 3개 달랐다. 채점은 GPU 로 본다.
- 검토 지적을 반영한 것: maxent 의 개수 선택·조합 빈도 대응·극단 입력을 고정하는 테스트 5건, 깨진 사전분포(길이 오류, NaN)를 거부하는 검사, 번들에 사전분포 출처(캐시 경로, 통화 목록, 통화 수) 기록, Validation 캐시 경로 거부.
- 알고 두는 한계: 상위 k개 제한은 전체 조합 탐색과 0.67% 순간에서 다르다(손실 평균 3e-5). 60회 반복 뒤에도 0.68% 순간은 증상별 확률이 0.001 넘게 어긋난다(최대 0.0026).

**주의**: 이 이득은 증상 1개 통화에서 얻고 2개 이상 통화에서 잃는 교환이다. 평가셋의 증상 1개 통화 비율이 dev(67%)보다 낮아 60% 가 되면 이득이 0, 55% 면 손해다. 되돌리려면 번들을 `--rule expected` 로 다시 묶으면 된다.
