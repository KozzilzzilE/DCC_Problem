- 검토 담당이 확인한 전제 (모두 확인됨): 캐시 발화의 순서·시각·화자·전사가 템플릿과 fit 전체에서 불일치 0, wav 결손·잘림 0, E011 교차 학습 확률표의 겹 구성에 누수 없음(held 다섯 개가 fit 을 정확히 덮고 dev 와 겹침 0), 규정상 `utt.audio` 사용 가능(추론에서 원본 wav 재로딩은 금지).
  - 밝혀 둘 것: 검토 중 템플릿 `load_samples` 를 train 폴더 전체에 돌려, 템플릿 내부 필터가 dev 통화 json 의 symptom 필드를 읽었다. 값을 출력하거나 쓰지는 않았다. 이후 검토는 필요한 통화만 담은 임시 폴더로 했다.
- **결과를 보기 전 설계 수정**: 원 설계는 증상별 LightGBM 으로 T(텍스트 확률 9개)와 T+A(+음성)를 비교하는 것이었다. 검토 담당이 T 만으로 재 보니 LightGBM T 가 평균 AUC 0.8701 로, 확률을 그대로 쓴 T_raw 0.8848 보다 0.015 낮았다(9종 모두). 판정 문턱의 3배라, 1차 분류기를 로지스틱 회귀(표준화, C=1)로 바꾸고 판정에 "T_raw 도 이겨야 한다"와 "증상 하나만 통과하면 그 증상의 대조군은 0 을 포함해야 한다"를 더했다. 구현 담당은 이 수정 전에 본 실행을 돌리지 않았다.
- 방법 (`runs/E020_audio/stage1.py`): T = E011 확률표의 마지막 순간 9종 로짓(그 통화를 학습에 안 쓴 모델의 출력). A = 8층 발화 임베딩의 통화 평균·표준편차 → 표준화 → PCA 64(학습 겹에서만 fit). 5겹 교차검증(`KFold(5, shuffle, 2026)`), 통화 단위 짝 부트스트랩 2,000회. 대조군 = 음성 블록만 통화끼리 섞은 것.

| 1차 (로지스틱), 9종 평균 AUC | 값 | 차이 [95% 구간] |
|---|---|---|
| T_raw (확률 그대로) | 0.8848 | |
| T | 0.8832 | T − T_raw −0.0016 [−0.0022, −0.0010] |
| T+A | 0.8757 | T+A − T **−0.0075 [−0.0090, −0.0061]**, T+A − T_raw −0.0091 [−0.0107, −0.0076] |
| 대조군 (음성 섞음) | 0.8771 | 대조군 − T −0.0061 [−0.0076, −0.0046] |
| A (음성만) | 0.5980 | |

- 증상별: 9종 모두 T+A − T 가 음수다. 음성만으로는 열상 0.749, 복통 0.640, 고열 0.622, 전신쇠약 0.614, 호흡곤란 0.601 이고 나머지는 0.53~0.55 다.
- 판정에 쓰지 않은 것
  - 대조군이 0 근처가 아니다. 로지스틱에 65차원을 더하는 것만으로 0.006 을 잃는다. 그래서 같은 차원끼리 비교한 T+A − 대조군을 탐색으로 쟀다: **−0.0014 [−0.0034, +0.0007]**. 차원 손해를 빼도 음성이 더하는 것이 없다. 전신쇠약만 −0.0049 [−0.0099, −0.0002].
  - 잔차 부스팅(LightGBM, 자기 증상 로짓을 init_score): 잔차T+A − 잔차T −0.0015 [−0.0042, +0.0011], 증상별 구간 모두 0 포함. 원 설계 LightGBM: 원T+A − 원T −0.0018 [−0.0043, +0.0007].
  - 층 바꾸기: 4층 T+A − T −0.0072, 12층 −0.0075.
  - 텍스트가 512토큰에서 잘린 161통화를 빼도 −0.0077 로 같다.
  - 세 분류기 모두 같은 방향이다. 판정을 수정한 뒤의 `stage1.py` 는 별도 재검토를 하지 않았다.
- 판정: **사전 등록 기준 (a)·(b) 모두 불충족, 2단계로 가지 않는다.**
- 해석: 음성에도 증상 정보는 있다(음성만 AUC 0.60, 열상 0.75). 하지만 그 정보는 전사가 이미 다 담고 있다. 신고자가 환자 본인이 아닌 통화가 많고, 8kHz 전화 음성을 올린 것이라 비언어 신호가 약한 것으로 본다. 조사 담당이 찾은 선행 연구(MultiQT, 응급 통화 증상 검출)에서도 음성을 더한 이득은 텍스트 대비 F1 +1~2점이었다.
- 열어 둔 것: 전화 음성으로 사전학습한 `facebook/wav2vec2-large-robust`(Apache-2.0)나 `microsoft/wavlm-large` 로 바꾸면 달라질 여지는 있다. 다만 같은 차원 대조군 대비 상한이 +0.0007 이라 기대가 작고, 추론에 발화마다 음성 모델을 더 돌려야 한다. 이번 마감 안에서는 음성 방향을 닫는다.
- 쓰지 않을 것 (조사 담당): Hugging Face 에 AI-Hub 119 데이터로 학습했다고 밝힌 모델이 있다. 평가 데이터가 섞였을 수 있어 쓰지 않는다. 감정·나이 판별로 미세조정된 모델(audeering 등)은 외부 라벨과 비상업 라이선스가 걸려 있어, 쓰려면 주최측 문의가 먼저다.
