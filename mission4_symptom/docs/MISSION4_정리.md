# Mission 4 정리

## 한 줄 요약

**제출할 모델은 완성됐고, Validation 점수는 4-1 0.5302, 4-2 0.5042다.** 그 뒤로 시도한 개선은 모두 효과가 없었다. 점수를 막는 것은 모델이 아니라 "아직 말하지 않은 증상"과 "전사에 없는 라벨"이다.

## 1. 문제

119 신고 통화를 발화 하나씩 받으면서 환자 증상 9종(고열, 구토, 두통, 복통, 어지러움, 열상, 오심, 전신쇠약, 호흡곤란)을 맞힌다.

| | 무엇을 하나 | 점수 |
|---|---|---|
| **4-1** | 발화가 들어올 때마다 그 순간의 증상을 답한다 | 모든 순간의 점수 평균 |
| **4-2** | 언제 멈추고 답할지 스스로 정한다 | Macro-F1 × 조기판단력 (일찍 멈출수록 유리, 끝까지 들으면 0.5배) |

규칙: 그 순간까지 들은 발화만 쓴다. Validation 데이터는 학습에 쓸 수 없다.

## 2. 최종 모델

1. **증상 예측기 3개의 평균.** 한국어 모델 KLUE-RoBERTa 를 119 전사로 한 번 더 익힌 뒤 학습했다. 둘은 "통화 앞부분만 보고 맞히기", 하나는 "통화 전체 보고 맞히기"로 학습했다.
2. **4-1: 몇 개를 답할지 고르기.** 확률 0.5 를 넘는 증상을 다 내는 대신, 실제 증상 조합이 얼마나 흔한지(증상 1개인 통화가 67%)를 함께 보고 점수 기댓값이 가장 큰 조합을 낸다.
3. **4-2: 멈출 때를 배우는 작은 모델.** "지금 멈추면 받을 점수"와 "더 들으면 얻을 이득"을 예측해, 충분하면 멈춘다.

| | Validation (최종 모델) | dev (Training 안에서 떼어 둔 2,920통화) |
|---|---|---|
| 4-1 | **0.5302** | 0.5517 |
| 4-2 | **0.5042** | 0.5064 |

Validation 은 모든 값을 정한 뒤 한 번만 돌렸고, 그 결과로 바꾼 값은 없다.

## 3. 점수를 올린 과정 (dev 기준)

| 단계 | 4-1 | 4-2 |
|---|---|---|
| 예선 모델 그대로 (끝까지 듣기) | 0.5014 | 0.3276 |
| 빈 답 막기 / 확신하면 멈추기 | 0.5353 | 0.4814 |
| 앞부분 학습 + 점수 기댓값으로 답하기 | 0.5447 | 0.4935 |
| 실제 증상 조합 분포로 답하기 | 0.5485 | 0.4935 |
| 모델 3개 평균 | 0.5517 | 0.4983 |
| 멈출 때를 배우는 모델 | **0.5517** | **0.5053** |

**모델을 바꾸는 것보다 "언제, 몇 개를 답할지" 정하는 규칙이 점수를 더 많이 올렸다.**

## 4. 해 봤지만 안 된 것

| 시도 | 결과 |
|---|---|
| 다른 한국어 모델 (KF-DeBERTa) | 더 낮음 |
| 더 큰 모델 (RoBERTa-large) | 잡음 수준, 3배 느림 |
| 모델 더 많이 평균 | 3개에서 포화 |
| 증상 개수 같이 예측 | 개수를 못 읽음 |
| 오심 따로 다루기 | 오심 통화 87.5% 는 전사에 메스꺼움 표현이 없음 |
| [대원]/[신고자] 표시 | 효과 없음 |
| 신고자 음성 추가 | 전사가 이미 다 담고 있음 |

## 5. 왜 더 안 오르나

- **아직 말하지 않은 증상은 맞힐 수 없다.** 통화 전체를 미리 알아도 4-1 은 0.646 이 한계다.
- **라벨이 전사에 없다.** 정답 증상이 통화에 한 번도 나오지 않는 통화가 35% 다.
- **모델은 이미 잘 듣고 있다.** 신고자가 증상을 말한 발화에서 93% 를 맞힌다.

## 6. 작업 방식

- **Validation 은 학습·값 고르기에 쓰지 않는다.** Training 안에서 떼어 둔 dev 로 판정한다.
- **판정 기준을 결과 보기 전에 정한다.** 차이가 0.002 를 넘고 신뢰구간이 0 을 벗어나야 채택한다.
- **잡음보다 작은 차이는 무시한다.** 같은 설정도 seed 만 바꾸면 점수가 0.002 쯤 움직인다.
- **실제 제출 방식으로 돌려 확인한다.**
- **역할을 나눠 한다.** 구현 → 처음 보는 사람의 검토 → 조사.

**발표에서 강조할 것**

- 증상마다 판단 가능한 시점이 다르다. 고열·열상은 대개 5번째 발화에서 판단하고, 전신쇠약은 12번째쯤까지 듣는다. 빨리 드러나는 증상은 출동 준비를 앞당기는 데 쓸 수 있다.
- 오심은 말로 잘 드러나지 않아 사람의 확인이 계속 필요하다.
- 시스템은 확신이 설 때만 멈추고, 애매한 통화는 끝까지 듣는다.
